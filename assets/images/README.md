# Images

Drop brand image assets here (logo, etc.).

## Logo

Add your logo as `logo.svg` (preferred) or `logo.png` in this folder.

Once it's here, tell me and I'll swap the text wordmark (`LIFTOFF.`) in the hero
and footer for the real logo image — or you can reference it directly:

```html
<img src="assets/images/logo.svg" alt="Liftoff" height="40">
```

Suggested files:
- `logo.svg` / `logo.png` — primary logo (for light backgrounds)
- `logo-light.svg` / `logo-light.png` — reversed/white logo (for the deep-blue footer)
