# Video

Background video for the hero section.

## Hero background

Add your video here as **`hero.mp4`** (H.264/MP4 — broadest browser support).
Optionally also add **`hero.webm`** for smaller file size; the page will use it when supported.

The hero is already wired to look for these files, so once `hero.mp4` is committed it will
autoplay (muted, looped) behind the headline.

### Recommended specs
- **Format:** MP4 (H.264) + optional WebM
- **Resolution:** 1920×1080 (landscape)
- **Length:** 8–20s seamless loop
- **Size:** keep under ~5–8 MB if possible (it's muted/looping background, not feature video)
- **Poster (optional):** add `../images/hero-poster.jpg` — shown while the video loads / if it can't play

A translucent warm-white scrim sits over the video so the deep-blue headline stays readable.
If your video is dark and you'd rather have white text on a darkened video instead, tell me and
I'll flip the hero treatment.
